# SubChecker

CLI-инструмент для проверки VPN-подписок в условиях DPI/ТСПУ.

Обычные чекеры меряют пинг до сервера — но с DPI и ТСПУ провайдер режет сам протокол
маскировки, а не ICMP. Сервер пингуется, а трафик внутри туннеля не идёт.

SubChecker поднимает реальное ядро (sing-box) локально и проверяет
проходимость трафика через туннель: живой ли он, работают ли заблокированные
ресурсы, какая реальная скорость.
